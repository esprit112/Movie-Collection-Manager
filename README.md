# 🎬 Movie Collection Manager - Version 3.0

## Quick Start

1. **Install Dependencies:**
   ```bash
   pip install -r requirements.txt
   ```

2. **Run the Application:**
   ```bash
   python main.py
   ```

3. **Optional: Setup TMDB API Key**
   - Visit https://www.themoviedb.org/settings/api
   - Create a free account and get your API key
   - Enter it when prompted in the app

## Features

✅ Search and add movies from TMDB
✅ Import local movie files  
✅ Download movie posters automatically
✅ Track watched status and personal ratings
✅ Multiple view modes (grid/detail)
✅ Export collection to CSV
✅ Automatic database backups
✅ Statistics and analytics

## File Structure

- `main.py` - Main application
- `themes.py` - Theme configuration
- `utils.py` - Utility functions
- `database.py` - Database operations
- `tmdb_api.py` - TMDB API integration
- `requirements.txt` - Dependencies
- `config.json` - User configuration

## Support

Check `movie_app.log` in the application folder for error logs.
